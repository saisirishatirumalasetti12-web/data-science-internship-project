## Project Overview
This project analyzes student performance data using Python. The aim is to understand students' marks and identify factors that may affect their academic performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Project Features
- Load student data
- Clean and process the data
- Calculate average marks
- Analyze student performance
- Display results using charts

## Learning Outcome
Through this project, I learned the basics of data cleaning, data analysis, and data visualization using Python.
